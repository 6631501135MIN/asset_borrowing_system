🚀 HOW TO CHANGE HOST (3 WAYS)

1️⃣  Using Helper Script (Recommended)
   ./change_host.sh
   
   Interactive menu:
   - localhost (127.0.0.1)
   - 192.168.1.173 (Your local IP)
   - 0.0.0.0 (All interfaces)
   - Custom IP

2️⃣  Manually Edit .env File
   Open .env file
   Change: HOST=192.168.1.173
   To:     HOST=localhost  (or any IP)
   Save and restart: npm start

3️⃣  Quick Command Line
   # Change to localhost
   sed -i '' 's/^HOST=.*/HOST=localhost/' .env
   npm start
   
   # Change to local IP
   sed -i '' 's/^HOST=.*/HOST=192.168.1.173/' .env
   npm start
